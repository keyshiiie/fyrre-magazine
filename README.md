Fyrre Magazine — 
Многостраничный новостной сайт (журнал об искусстве и жизни), сверстанный по макету. Проект создан как часть портфолио для демонстрации навыков современной фронтенд-разработки.

На данный момент реализована только клиентская часть (Frontend). В качестве источника данных используются локальные моковые файлы (Mock Data), подготовленные для легкой интеграции с будущим API.

🛠 Стек технологий
Фреймворк: Next.js (App Router)

Язык: TypeScript

Стилизация: Tailwind CSS

Иконки: Lucide React

Шрифты: Google Fonts (через next/font)

Изображения: Next.js <Image /> (оптимизация, ленивая загрузка)
